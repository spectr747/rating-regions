# Рейтинг регионов РФ

Интерактивный дашборд по ключевым показателям эффективности глав субъектов РФ (Росстат, 2020–2024).

Откройте `index.html` (или страницу GitHub Pages этого репозитория) и войдите. Логин и пароль у владельца репозитория.

Содержимое дашборда хранится в `index.html` в зашифрованном виде (AES-GCM, ключ из логина и пароля через PBKDF2-SHA-256). Без верных логина и пароля данные прочитать нельзя.

## Обновление дашборда

```sh
DASH_USER=логин DASH_PASS=пароль node tools/encrypt.mjs путь/к/dashboard.html index.html
```

Скрипт берёт исходный `dashboard.html`, шифрует его и собирает `index.html` со страницей входа (`tools/login.tpl.html`). Логин и пароль в репозиторий не записываются.
